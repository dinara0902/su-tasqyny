## Мәселе және мақсат

**Мәселе.** 2024 жылдың көктемінде Қазақстанның бірнеше облысында су тасқыны болып, ондаған мың адам эвакуацияланды. Мұндай кезде үш сұрақ тез шешілуі керек:

- қай жолмен қауіпсіз шығуға болады;
- қай жолды су басты, ал қай хабар қате;
- кімді қай эвакуация пунктіне жіберген дұрыс, пункт толып кетпес үшін не істеу керек.

**Мақсат.** Осы үш сұраққа AI алгоритмдерімен жауап беретін, браузерде ашылатын интерактивті карта жасау. Әр алгоритмнің нәтижесі картада көрінеді және қадамдап түсіндіріледі.

## Мүмкіндіктер

- **Қауіпсіз маршрут.** Үйді таңдасаң, жүйе су басқан жолдарды айналып өтіп, ең жақын қауіпсіз пунктке дейінгі жолды көрсетеді.
- **Хабарламалар.** Пайдаланушы «бұл жолды су басты» немесе «бұл жол құрғақ» деп белгілейді. Жүйе хабарламаларға толық сенбейді, су басу ықтималдығын біртіндеп жаңартады.
- **Адамдарды бөлу.** Отбасыларды пункттерге бөледі: орын саны, медициналық көмек, қашықтық ескеріледі.
- **Параметрлер.** Пункттің сыйымдылығын, хабарлама сенімділігін, отбасы құрамын өзгертуге болады.
- **«Қалай ойлады?» режимі.** Әр алгоритмнің шешімі қадамдап көрсетіледі.

## AI тақырыптары

Барлық алгоритм JavaScript-те нөлден жазылған. Сыртқы AI API немесе дайын ML кітапханасы қолданылмайды.

| № | Апта | Тақырып | Алгоритм | Сайтта не істейді | Жауапты |
|---|---|---|---|---|---|
| 1 | 2-апта | Іздеу | **A\***, салыстыру үшін **BFS** | Су басқан аймақты айналып өтетін ең қауіпсіз жолды табады | Марат Нәрлі |
| 2 | 3-апта | CSP | **Backtracking + MRV + Forward Checking** | Отбасыларды эвакуация пункттеріне бөледі | Нұрдаулет Шұғыла |
| 3 | 6-апта | Ықтималдық | **Байес ережесі** | Хабарламалар бойынша жолды су басу ықтималдығын бағалайды | Жарқын Динара |

## Жүйе қалай жұмыс істейді

Үш модуль бір-бірімен байланысты:

```
 Тұрғындардың хабарламалары
            │
            ▼
   ┌──────────────────┐   әр жолдың су басу ықтималдығы P
   │  Байес (6-апта)  │──────────────────────┐
   └──────────────────┘                      ▼
                                   ┌──────────────────┐
                                   │   A* (2-апта)    │  P жоғары жол — қымбат немесе жабық
                                   └──────────────────┘
                                             │ әр үйден әр пунктке дейінгі қашықтық
                                             ▼
                                   ┌──────────────────┐
                                   │   CSP (3-апта)   │  кім қай пунктке барады
                                   └──────────────────┘
                                             │
                                             ▼
                                  Картадағы маршрут пен бөлу кестесі
```

1. **Байес** әр жол ұяшығы үшін «су басты» деген ықтималдықты есептейді.
2. **A\*** сол ықтималдықты жол құнына қосады: P шекті мәннен жоғары болса, жол жабық деп саналады.
3. **CSP** A\* тапқан қашықтықтарды қолданып, отбасыларды пункттерге бөледі.

## Іске қосу

Қажет: [Node.js](https://nodejs.org) 18 немесе одан жаңа нұсқасы. Сыртқы кітапхана орнатудың қажеті жоқ.

```bash
git clone [толтырыңыз: репозиторий сілтемесі]
cd su-tasqyny
npm test        # барлық тесттер
npm start       # локал сервер: http://localhost:3000
```

Немесе `index.html` файлын браузерде тікелей ашуға болады.

**Vercel-ге жариялау:** vercel.com → Add New → Project → осы репозиторийді таңдау → Deploy. Баптауларды өзгертудің қажеті жоқ.

## Шектеулер

- Карта ойдан құрастырылған, нақты география мен су деңгейінің деректері қолданылмайды.
- Су деңгейі уақыт бойынша өзгермейді: жүйе бір сәттің жағдайын қарастырады. Келесі қадам ретінде 7-аптадағы HMM қосуға болады.
- Хабарламалардың сенімділігі барлық адам үшін бірдей деп алынған.
- CSP шешімі табылмаса (орын жетпесе), жүйе мұны ашық айтады, бірақ адамдарды өзі бөлмейді: шешімді штаб қабылдайды.
- Бұл оқу прототипі. Нақты эвакуацияда пайдалану үшін ресми деректер мен мамандардың тексеруі қажет.
